Joomla 6.1.3 Known Issues
=========================

Last Updated: 22 August 2026

[Joomla 6.1.3](https://github.com/joomla/joomla-cms/releases/tag/5.4.7) was released on 18 August 2026.

## Issue [#48273](https://github.com/joomla/joomla-cms/issues/48273) – Cannot create overrides in template manager

When creating an override in the template manager, the override is not created and the following error is displayed:

```
Joomla\Filesystem\Path::check() - Snooping out of bounds @ com_contact/categories 
```

Pull Request [#48171](https://github.com/joomla/joomla-cms/pull/48171) introduced this regression.

### Resolution

This issue will be resolved in Joomla 6.1.4.

### Workaround (until Joomla 6.1.4)

Replace the file `/administrator/components/com_templates/src/Model/TemplateModel.php` with the following version:

[/administrator/components/com_templates/src/Model/TemplateModel.php]([https://raw.githubusercontent.com/joomla/joomla-cms/eacfb318d7b121cc316b482e3050343c681e924c/administrator/components/com_templates/src/Model/TemplateModel.php](https://raw.githubusercontent.com/joomla/joomla-cms/a8ccf40f11b066639e78e83f3503e7ed18438f6a/administrator/components/com_templates/src/Model/TemplateModel.php))
