Joomla 5.4.9 Known Issues
=========================

Last Updated: 29 September 2026

[Joomla 5.4.9](https://github.com/joomla/joomla-cms/releases/tag/5.4.9) was released on 29 September 2026.

## [#48527](https://github.com/joomla/joomla-cms/pull/48527) – Web Services API PATCH requests fail

Trying to update an item (for example, a banner or a user entry) via Web Services API fails with a fatal error.

The regression was introduced while porting security fixes to the Joomla 5.x branch.
A required `use` statement was missing.

### Resolution

This issue will be resolved in Joomla 5.4.10.

### Workaround (until Joomla 5.4.10)

In file `libraries/src/MVC/Controller/ApiController.php`, add the following `use` statement:
```
use Doctrine\Inflector\InflectorFactory;
```
