Joomla 6.1 to 6.2 Upgrade Notes
===============================

An explanation of the code changes for each version of Joomla.
If you follow from the version of your current code until the version you want to support you should come across all the changes you need to make.

Joomla 6.2.1 introduces changes to Web Services API authorization and DELETE responses. See [Removed and Backward Incompatibility](removed-backward-incompatibility.md) for the required permission updates and migration details.
See [Joomla 6.2.1 Known Issues and Compatibility Notes](known-issues/6.2.1.md) for guidance for site administrators and affected third-party extensions.
